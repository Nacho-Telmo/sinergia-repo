Repositorio Sinergia

Este repositorio es mantenido de forma colaborativa por los miembros de la Comunidad de Sinergia.

Paquetes binarios optimizados para Arch Linux y distribuciones derivadas.

Unirse al Telegram

Paso 1: Agregar la llave GPG

Importa y firma la clave pública del repositorio para verificar la autenticidad de los paquetes:

curl -sS https://Nacho-Telmo.github.io/sinergia-repo/sinergia.gpg | sudo pacman-key --add -
sudo pacman-key --lsign-key 4CBFA5A14BB153A7

Paso 2: Agregar el repositorio a pacman.conf

Añade las siguientes líneas al final de tu archivo /etc/pacman.conf:

[sinergia]
SigLevel = Required DatabaseOptional
Server = https://Nacho-Telmo.github.io/sinergia-repo/x86_64

Paso 3: Sincronizar bases de datos

Fuerza el refresco de las bases de datos de repositorios para reconocer los nuevos paquetes:

sudo pacman -Syy

🚀 Cómo agregar el repositorio

Para añadir sinergia-repo a tu sistema Arch Linux o derivados (Manjaro, EndeavourOS, etc.), edita tu archivo /etc/pacman.conf agregando al final las siguientes líneas:

[sinergia]
SigLevel = Optional TrustAll
Server = https://raw.githubusercontent.com/Nacho-Telmo/sinergia-repo/main/x86_64

Luego, sincroniza la base de datos de paquetes ejecutando:

sudo pacman -Sy
